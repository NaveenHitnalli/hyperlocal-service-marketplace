# 🛠️ Hyperlocal Service Marketplace (Urban Company Clone)

A full-stack MERN (MongoDB, Express, React, Node.js) application that connects customers with service providers for hyperlocal needs like home cleaning, repairs, etc.

Deployed with **Render**, styled with **Tailwind CSS**, **Bootstrap**, and animated using **Animate.css** via CDN.

---

## 🌐 Live Demo

- 🔗 Frontend: https://marketplace-frontend.onrender.com
- 🔗 Backend API: https://marketplace-backend.onrender.com/api

---

## 🔧 Tech Stack

| Layer     | Tech                                                   |
|-----------|--------------------------------------------------------|
| Frontend  | React, Tailwind CSS, Bootstrap, Animate.css (CDN)      |
| Backend   | Node.js, Express, JWT, Bcrypt, Razorpay API            |
| Database  | MongoDB Atlas                                          |
| Auth      | JWT Token-based Auth with Role (User, Provider, Admin) |
| Payments  | Razorpay Integration                                   |
| Hosting   | Render.com                                             |

---

## ✨ Features

### 👤 Users
- Register/Login
- Browse services
- Book a service with date & time
- Pay securely via Razorpay
- View dashboard
- Submit ratings & reviews

### 🧑‍🔧 Providers
- Login
- Create new services
- Manage bookings (status update)
- Provider dashboard

### 👑 Admin (optional)
- View all users, services, bookings
